# Self-Hosting Milestone Context

The milestone language established during September 2026 is:

- D0 — Dogfood-ready
- D1 — Self-Hosting Threshold
- D2 — Dogfood Cutover
- D3 — Self-Hosted Development
- D4 — Closed Development Loop
- D5 — Autonomous Self-Hosting Alpha

Original planning targets were:
- D0: 2026-09-29
- D1: 2026-10-09
- D2: 2026-10-16
- D3: 2026-10-30
- D4: 2026-11-13
- D5: 2026-12-04

Treat dates as planning targets, not immutable promises. Re-evaluate them against actual repository state.

## Meaning
D0: Agentic Studio can perform a real useful Agentic Studio change through the Mission runtime and preserve evidence.

D1: enough of the development loop is internal that Studio can prepare a GitHub-ready change/PR without external prompt relaying.

D2: routine Agentic Studio development can primarily move into Agentic Studio itself.

D3: the self-hosted workflow is dependable enough for regular development.

D4: implementation, validation, delivery feedback, repair, and evidence form a closed development loop.

D5: bounded autonomous backlog work can proceed with appropriate policies, budgets, approvals, and supervision.

The current Alpha.2 human verification establishes a functional Studio Chat dogfood surface. The next priority is closing GitHub intake/delivery/CI feedback so the self-hosting threshold becomes practical.
